# Roadmap: восстановление переносов строк в корпусе (АКТИВНЫЙ)

> **Статус:** в работе (заведён 2026-06-26). Цель — вычистить из ZML-корпуса два
> класса повреждений переносов строк, оставшихся от устаревшего конвейера
> proza.ru→html→zml. **Конвейер БОЛЬШЕ НЕ ИСПОЛЬЗУЕТСЯ** — все правки идут прямо в
> `.zml` (см. PROJECT.md). Документ самодостаточен для исполнения с холодного
> контекста: ниже встроены все нужные сниппеты (scratchpad-скрипты не сохраняются).

## 0. Фон

Корпус свёрстан в два шага старым конвейером: (1) proza.ru → «оригинальный html»
(прямая LLM-вёрстка, `legacy/`), (2) html → ZML (`cms-revival/convert/html_to_zml.py`).
Оба шага в разных местах теряли/портили авторские переносы строк. Инвариант проекта
(SPEC §9) — **каждый `\n` авторский, ничего не склеивать и не плодить**. Уже найдены и
исправлены ТРИ разных механизма (история ниже). Этот roadmap закрывает оставшиеся два.

Канон переносов всегда один: **строки стиха идут ПОДРЯД (один `\n`), пустая строка —
ТОЛЬКО реальный разрыв строфы.** В темах `.poem{white-space:pre-wrap}`, `[epi]`/`[quote]`
рисуют `\n`→`<br>`, пустая строка → новый `<p>`/строфа.

## 1. Источники истины

- **Bug A** (склейка в «оригинальном html») — `legacy_html` УЖЕ испорчен, поэтому
  истина = **proza.ru** по URL из `manifest.json` (`url`). Кодировка **cp1251**,
  текст в `<div class="text">`, переносы — `<br>`.
- **Bug B** (зафлужение при html→zml) — «оригинальный html» КОРРЕКТЕН (построчно),
  можно брать структуру оттуда; но proza.ru тоже годится и однозначнее. Реальные
  разрывы строф = промежуток ≥2 пустых строк в proza.

## 2. Два класса бага

### Bug A — склейка «белого стиха» в одну строку (upstream: proza→html)
Белый стих, который на proza.ru шёл по строкам, в «оригинальном html» склеен в
сплошной абзац (мало `<br>`). Эталон — **1AH** (рассказ «Стихотворение АРИ. Часть 2»):
весь корпус «ЧАСТЬ ВТОРАЯ» был ОДНИМ абзацем 433 слова. **Исправлено ✅** (обёрнут в
`[poem]`, 59 строк по proza).

Детект (надёжно только через proza): для статьи сравнить число «строк»
(непустых) в proza `<div class=text>` с числом строк/`<br>` в zml. Если proza даёт
много коротких строк, а zml — несколько длинных абзацев → склейка.

Кандидатская вселенная: **type `verse`(38) + `poem`(13)** = 51 шт., ПЛЮС статьи типа
`prose`/`dialog`, которые по сути белый стих (как 1AH — он `type: prose`!). Семья
«ДОБРАЯ РЕЧЬ / Стихотворение АРИ»: `1ATA`(ч.1), `1AH`(ч.2 ✅), `1BA`(ч.3),
`1AN`,`1B9`,`193`,`24C`,`1C1`,`255`,`28P`,`323`,`364`,`28MA`,`217A`,`255A` — проверить
в первую очередь.

### Bug B — зафлужение пустыми строками между строк (html→zml)
Стих с КОРРЕКТНЫМИ переносами при html→zml получил пустую строку между КАЖДОЙ строкой
(каждая строка стала отдельным абзацем/строфой). Эталон — **1BA** (часть 3): `[poem]`
из 234 строк и `[epi]` из 8 — все через пустую строку. **Исправлено ✅** (дефлуд по proza).

Детект (локально, без сети) — скрипт §4.2. Текущие кандидаты (на 2026-06-26):
`35Q`(quote,16), `179`(epi,12), `04I`(poem,10), `2AA`(quote,6), `27K`(poem,8).
⚠️ `quote`-кандидаты проверять глазами: иногда каждая строка — отдельный
афоризм/цитата, и пустые строки ЛЕГИТИМНЫ (не флуд). Чинить только настоящий флуд стиха.

## 3. Метод фикса (общий, оба бага)

Единый приём — **разбивка по границам proza**, сохраняющая символы ZML:
1. Взять содержимое блока в ZML, схлопнуть в одну строку (`glued`).
2. Получить эталонные строки из proza (Bug A/B) ИЛИ из legacy_html (Bug B).
3. Фиделити-ассерт: **число слов** `glued` == сумма слов эталонных строк (отдельные
   токены могут отличаться: маркер сноски `*4`↔`[^4]`, кавычки `"`↔`«»` — это ОК).
4. Разложить слова `glued` по строкам согласно числу слов в эталонных строках.
5. Пустая строка между строфами — только где в proza промежуток ≥2.
6. Обернуть: стих-тело → `[poem]`; стих-эпиграф → `[epi kind="verse"]`.
   ⚠️ `[poem]` при `caps: off` (дефолт) НЕ капитализирует строки — безопасно для
   continuation-строк («дома отдохни» после «Ляг,»).

После правок: `node cms-revival/editor/build_views.mjs <id…>` → проверить рендер
(число `<br>`/строк == ожидаемому, нет двойных пустых) → `imyavel/push.bat`.

## 4. Встроенные скрипты (для холодного контекста)

### 4.1 proza.ru → построчно (cp1251, div.text)
```python
import re; from bs4 import BeautifulSoup, NavigableString, Tag
def proza_lines(url_or_file):  # url_or_file: локальный html ИЛИ сырьё после curl
    raw = open(url_or_file,'rb').read().decode('cp1251')
    d = BeautifulSoup(raw,'html.parser').select_one('div.text'); parts=[]
    def w(n):
        for ch in n.children:
            if isinstance(ch,NavigableString): parts.append(str(ch))
            elif isinstance(ch,Tag):
                parts.append('\n' if ch.name=='br' else '');  w(ch) if ch.name!='br' else None
    w(d)
    # промежутки: список (blank_run_before, line); blank_run>=2 → разрыв строфы
    out=[]; blanks=0
    for l in ''.join(parts).replace('\r','').split('\n'):
        if l.strip()=='': blanks+=1
        else: out.append((blanks, re.sub(r'[ \t]+',' ',l).strip())); blanks=0
    return out
# curl: curl -sL -A "Mozilla/5.0" "<url>" -o proza.html   (url из manifest['url'])
```

### 4.2 Скан Bug B (флуд) — локально
```python
import re,glob,os
ZML=r'docs/art'
for p in sorted(glob.glob(ZML+'/*.zml')):
    art=os.path.splitext(os.path.basename(p))[0]; txt=open(p,encoding='utf-8').read()
    for tag in ('poem','epi','quote'):
        for m in re.finditer(r'\['+tag+r'\b[^\]]*\]\n(.*?)\n\[/'+tag+r'\]',txt,re.S):
            lines=m.group(1).split('\n'); ci=[i for i,l in enumerate(lines) if l.strip()]
            if len(ci)<6: continue
            bg=sum(1 for a,b in zip(ci,ci[1:]) if b-a>1); r=bg/(len(ci)-1)
            if r>=0.6: print(art,tag,len(ci),round(r,2))
```

### 4.3 Разбивка glued по эталонным строкам (ядро фикса §3)
```python
def split_by(glued, plines):           # plines: список строк-эталонов (непустых)
    words=glued.split()
    assert len(words)==sum(len(h.split()) for h in plines), 'WORD COUNT MISMATCH'
    res=[]; wi=0
    for h in plines:
        n=len(h.split()); res.append(' '.join(words[wi:wi+n])); wi+=n
    return '\n'.join(res)              # строфы вставлять там, где proza blank_run>=2
```
