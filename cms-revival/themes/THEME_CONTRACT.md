# Ф2 — контракт темы (что обязана покрыть КАЖДАЯ из 5 тем)

Тема = **один самодостаточный `style.css`**, который стилизует фиксированный
**контракт классов**, который эмитит `cms-revival/editor/render.js` (ZML1) +
шаблон `editor/data/template.html`. Тема **form-agnostic**: обязана красиво
сверстать любой тип контента (проза / стих / эпиграф / эпилог / цитата / сноски /
музыка / TOC / крошки / byline / колофон), а НЕ только «свою» форму.

## Вход для автора темы (читать перед написанием)
- `cms-revival/editor/render.js` — точные классы/структура HTML (ниже сжато).
- `cms-revival/zml1/demo.zml` — покрывает ВСЕ блоки = тестовая статья галереи.
- `cms-revival/zml1/style.css` — РАБОЧАЯ референс-тема (generic ZML1): полное
  покрытие контракта; брать как структурный скелет, **скин менять**.
- `editor/data/template.html` — обёртка страницы (body.article-page > .wrap.wide …).

## Контракт селекторов (всё должно быть оформлено)
- Каркас: `body`, `.wrap`, `.wrap.wide`, `article`, `nav.article-nav`, `footer.footer`.
- Шапка: `header.breadcrumbs` (+ `a`, `.sep`), `h1#article-title`, `p.byline` (+ `a`).
  **H1-sup (fn-ревью, вердикт 2):** `h1#article-title sup a` — маркер сноски в H1 обязан
  быть НА ГЛАЗ отличим от текста заголовка (мельче/другая гарнитура/цвет).
- Заголовки тела: `article h2` (+ `.back-to-toc`), `h2.subtitle`, `article h3` (= `###`,
  вложенный уровень; TOC рисует его вторым уровнем `details.article-toc ol ol`).
- Абзацы: `p`, `p.attribution`, `p.colophon`; красная строка/отступы — на усмотрение темы.
- Оглавление: `details.article-toc` (+ `summary`, `ol`, `li`, `a`).
- Стих: `.poem` (+ `.poem .title` / `.poem-title`). `white-space:pre-wrap`, меру строки держит тема.
- Стихи-прозой `[faw]` (ZML3 §2.5): `.faw` + `.faw-l.a` / `.faw-l.b` (чередование строк-сегментов).
  Тема ОБЯЗАНА задать режим и чередование: **монолит** `.faw-l{display:inline}` (swiss/A_editorial/
  cyberpunk — текст течёт прозой, границы видны сменой стиля) ИЛИ **построчно** `.faw-l{display:block}`
  (B_manuscript/ar_deco). Два чередующихся стиля (.a/.b) должны делать границы строк различимыми на
  глаз. **Построчные темы ДОПОЛНИТЕЛЬНО:** (1) `.faw-l .faw-cap{text-transform:uppercase}` — заглавная
  первая буква строки (как в стихах; монолит `.faw-cap` НЕ трогает); (2) зазор-строфа `[faw sta=N]`
  идёт классом `.faw-se` (база даёт `margin-bottom`, тема может уточнить). База шаблона — `.faw{margin}`,
  фолбэк `:where(.faw-l){display:block}` и `:where(.faw-l.faw-se){margin-bottom}` (тема перебивает).
  Нумерованные пункты сквозь строки (§2.5) → инлайн-бейдж `.faw-pt` (id-якорь + запись в TOC); базовый
  вид (пилюля в `--accent`) в шаблоне, тема может оформить под свою кикер/секционную идиому.
- Иллюстрация тела `[img]` (ZML3 §2.7): `figure.zimg` (+ `.zimg img`, `.zimg figcaption`) — картинка
  отдельным блоком в потоке + опц. подпись. Структурная база (центр, `max-width:100%`, подпись
  мельче/приглушённая) — в шаблоне через `:where()` (0-специфичность). Тема МОЖЕТ уточнить рамку/
  тень/типографику подписи ПО АНАЛОГИИ со своим `img.cover` (обложкой); префикс `.zimg` обязателен,
  чтобы перебить базу. Картинка из `../img/`, `loading="lazy"`.
- Обрамление: `.epigraph`, `.epilogue`, `blockquote.q` (+ `::before` = `data-label`, `.cite`);
  оси kind: `.verse`, `.aphorism`, `.dedication` (`[epi kind=dedi]`, fn-ревью).
- Нумерация: `ol.num` (+ `li`, `li::marker`); скобко-стиль `ol.num.num-paren` (маркер «N)» —
  база в шаблоне, авторские номера держит `li[value]`).
- Маркированный список (fn-ревью): `ul.ul` — дефолтный значок темы через `--marker`
  (`li::marker{content:var(--marker)}` — база в шаблоне); `[ul marker=◆]` переопределяет
  инлайн-стилем.
- Служебные роль-строки (fn-ревью): `p.line`, `p.line-tags`, `p.line-dateline` — мелкая
  утилитарная строка в идиоме темы; буквица-цепочки темы ОБЯЗАНЫ пропускать `p.line`
  (`:not(.line)` в dropcap-селекторах).
- Группы сносок (fn-ревью): `[refs]`-блок выводится тем же `ol.notes`; глиф-серии — пункты
  `li.anon` с литеральным «¤N» (отдельных селекторов не требуют, но проверить вид).
- Музыка: `.music-group` (+ `::before`=`data-label`), `details.music` (+ `summary`,
  `.label`, `.title`, `.caret`, `.ext`, `.player iframe[16/9]`), `.music-noplayer`.
  Этикетка с маркером сноски (label несёт `[^N]` — 12F/2C3…): render эмитит реальный
  `.music-group.has-label-row > .music-label` (сноска резолвлена) — тема ОБЯЗАНА стилизовать
  `.music-label` идентично своему `::before` и прятать `::before` по `.has-label-row` (20:27 2026-06-12).
- `[shir]` грид муз-плиток (ZML3 §6.7, спец-страница «Песнь Ступеней»): структурная база
  (`.songgrid` адаптив-грид, `.song .yt[16/9]`+`.play`, lazy-iframe, `.song-broken`) — в
  шаблоне (`template_songs.html`); тема ОФОРМЛЯЕТ плитку под свою карточку — селекторы
  `.songgrid .song` (форма/рамка/тень), `.songgrid .song .yt:hover .play` (play в палитру),
  `.songgrid .song .t .trk-ttl/.trk-sep/.trk-art` (типографика подписи), `.songgrid .song .a a`
  + `.sep` (ссылки на статьи + разделитель ♪). Префикс `.songgrid ` обязателен (перебить базу).
- Сноски: `sup a` (реф), `ol.notes` (+ `li`, `li.anon`, `a.backref`, `li:target`),
  попап `.footnote-bubble` (+ `.show`, `.below`, `::after`-стрелка).
- Инлайн-ссылки: `a` (внешняя), `a.internal` (корпусная), `a.zohar` (зоарная), `em`, `strong`.
- Диалог: `div.dialog` (+ вложенные `<p>`-реплики) — семантическая пометка `[dlg]`;
  дефолт наследует прозу, тема МОЖЕТ стилизовать (активирован 2026-06-12).
- КАПС-замена: `.sb` (рендер сворачивает CAPS в `<span class="sb">` — тема решает вид:
  small-caps / полужир / и т.п.).
- Viewbar: `nav.viewbar` (+ `label`, `select`, `a.vb-orig`, `button.vb-edit[:disabled]`) —
  утилитарная строка над крошками (тема/ширина/Оригинал/Править). Структура (flex, прижата
  вправо, мелкий кегль) — в шаблоне; тема задаёт типографику/цвета в своей идиоме (для тёмных
  тем — ещё `select option{color/background}`). Должна читаться, но НЕ спорить с шапкой статьи.

## Требования качества (гейт Ф2)
- Отлично смотрится при СВОЕЙ родной ширине; при смене ширины — **не ломается**
  (менее идеальный вид допустим, поломки — нет).
- Тайп-скейл с потолком: сноска не мельче читаемости, заголовок не гипертрофирован,
  ограниченное отношение макс/мин.
- `:target`-подсветка активной сноски — baseline во всех темах.
- Никакого внешнего ресурса БЕЗ запасного варианта: веб-шрифты — `@font-face`/
  системный fallback-стек (в корпусе веб-шрифтов нет; держим system-safe).

## 5 тем и их родная ширина
1. **A — editorial** (якорь анти-регресса): тёплая кремовая бумага, old-style serif
   (Georgia/Iowan), терракотовый акцент, H1 слева + короткая линейка, выключка.
   Родная ширина ~1080 (широкая). = язык корпуса (тип `654`).
2. **B — manuscript/ceremonial** (якорь): у́же (~820), H1 по центру, бордо/золото,
   орнаменты-разделители, флерон/буквица. = тип `237`.
3. **cyberpunk / neon-noir**: тёмный фон, неон (cyan/magenta), техно-дисплей,
   скан-линии/глитч-акценты. Родная ширина — широкая.
4. **swiss / минимализм**: чистый sans (Helvetica/Arial-стек), сетка, воздух,
   флаговая (ragged-right) вёрстка, тонкие линейки. Родная — широкая.
5. **ar-deco**: геометрический люкс, золото/чёрный/глубокий фон, симметрия,
   тонкие двойные линейки, верх. регистр заголовков. Родная — средняя/широкая.

## Метод галереи (как проверяем)
`node themes/gallery.mjs <theme-file-stem> [zml]` рендерит demo (и реальные статьи)
через тему → `themes/gallery/*.html`; затем headless Chrome → PNG; смотрим глазом.
Имя CSS темы = `<stem>.css` в `themes/` (напр. `A_editorial.css`).
