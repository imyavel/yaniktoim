3. Полный прогон 352 (драйвер ниже) → инварианты: **ошибок 0 · коридор ≥338 · сноски 970**
   (количество может осознанно меняться — фиксировать здесь почему. История базы: сноски
   962→970 (35Q-фикс +8); коридор 339→338 (47H-фикс двойного автора раскрыл истинную cov 22S=0.962)).
4. Свериться, что фикс не зацепил чужие статьи: `cmp` out/*.zml против docs/art/*.zml
   ДО копирования — список изменившихся должен быть объясним.
5. Деплой: `cp out/*.zml ../../yaniktoim/docs/art/` + `node ../editor/build_views.mjs`.
6. Скрин-сверка зрением → статус здесь + строка в летопись roadmap (append-only).

**Драйвер прогона** (из `cms-revival/convert/`):
```python
import json, re, glob, os, importlib.util
spec = importlib.util.spec_from_file_location("conv", "html_to_zml.py")
conv = importlib.util.module_from_spec(spec); spec.loader.exec_module(conv)
ids = sorted(os.path.basename(p)[:-4] for p in glob.glob('out/*.zml'))
res = {}
for art in ids:
    conv.FLAGS.clear()
    zml, cov = conv.convert(art)
    res[art] = {"cov": round(cov,3) if cov is not None else None,
                "flags": [f for f in conv.FLAGS if f.startswith(f"[{art}]")]}
json.dump(res, open('corpus_run_v4.json','w',encoding='utf-8'), ensure_ascii=False, indent=0)
```
NB Windows-stdout: кириллица в print бьётся — выводить через
`io.open(1,'w',encoding='utf-8',closefd=False)` или писать в файл.
