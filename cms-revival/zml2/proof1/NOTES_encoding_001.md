## Что унаследовано из 237.zml без изменений (уже сделано вручную в zml1)
- **Перенумерация сносок** в порядок документа `[^1]…[^26]`; авторские произвольные `*9/*13/*7…`
  смапплены по позиции. Сноски-сироты (`*4/*6→…/*10/*28`) вынесены анонимными `[^]:` в хвост.
- **Чистка `;;;;`-артефактов proza.ru** уже выполнена в 237.zml (`::`→` — `, `;;;;` убраны,
  `;::)))`→`; — )))`). Руны `;` ≥2 в article.zml2 отсутствуют (проверено).
- Музыка живёт в **сносках** (`Музыка: X — Y` + URL на continuation) — здесь это аппарат, не тело;
  блок `[mus]` не вводим (sourceType-метка литерально в теле сноски, по спеке §4).
- `[[art]]`/`[url]` в continuation-строках сносок — как в zml1 (identity).

## Применённые правки ZML 2 (vs 237.zml)
1. **Заголовок-шапка.** Введён `#` = on-page H1 (авторский CAPS-титул, отличен от `frontmatter.title`);
   подзаголовок-жанр → `[sub]…[/sub]`. Эталоны рисуют masthead: eyebrow+title+genre+artline.
2. **`[epi]` → `[epi kind=…]`** (Q-вердикты): эпиграф-стих → `kind=verse`; прозаический манифест
   (КАТНУТ/ГАДЛУТ) → `kind=prose`; афоризм «НЕ ЖАЛЕЙ МЕРТВЫХ…» → `kind=aphorism`; диалог-цитата
   из Стиха Первого → `kind=prose`.
3. **Финальный возглас** «ОДНИМ СЛОВОМ ; БУДУЩЕЕ ЗА НАМИ;» → обёрнут в **`[cry]…[/cry]`** (Q7).
4. **КАПС литерально (Q/roadmap §2).** Операторский маркер `^ЛЮБИТЬ` снят → `ЛЮБИТЬ`. Авторские
   кареты из raw (`Воина^Исраэль`, `ПО^НАСТОЯЩЕМУ` в теле `[^11]`) оставлены литерально (`^` без
   спец-значения). Никакого small-caps/восстановления имён.

## Развилки A/B — ЗАКРЫТЫ оператором (ZML2_SPEC_006)
- **A. Конвенция H1 — узаконен `#`.** On-page H1 = body `#`, иначе тема берёт `frontmatter.title`
  (всегда = название с прозы). Без дублирования, без «нет заголовка» (фолбэк на FM). §1.0 спеки.
- **B. Синтаксис `term/leit` — `{term|текст}` / `{leit|текст}`** (семейство `{ключ|текст}`, как
  `{chapter|N}`). Применено в article.zml2:
  - `{term|КАТНУТ}`, `{term|ГАДЛУТ}` — определяющие вхождения в прозаическом эпиграфе.
  - `{leit|Мужчиной и Женщиной Он создал Их}` — рефрен на открытии 4 секций (молитва + 3 стиха).
  - Доксология «Свят Благословен Он» НЕ помечена (guidance §8); повторы рефрена в теле сноски
    `[^11]` («…Ты создал Их») НЕ помечены (аппарат, иной вариант, шум).

## Решено по ходу (для рендера)
- **Глифы.** Рендер оборачивает распознанные авторские глифы в `<span class="glyph">` (литеральный
  контент + крючок для CSS-тем; manuscript красит). Набор: `<\^/>` (руки вверх), `</v\>` (зеркальный,
  руки вниз), эмотиконы `:)`, `; — )))`, `;::)))`. `\`,`^`,`/` спец-значения не имеют. (ZML2_SPEC_005 §5.)

## `[[art]]` — резолв из manifest, без дубля (правка источника)
- `[[ID]]` пишется БЕЗ `|`-якоря; рендер подставляет название из `proof1\manifest.json`
  (заглушка: 255B/1BQ/1C8B + 237). Литеральные заголовки убраны из 3 сносок (`[^16]/[^23]/[^25]`),
  канон: `См. также: [[ID]] — Автор`. (ZML2_SPEC_009 §8.) «Моя Ть;Mа.» очищено в manifest → «Моя Тьма».
- **Для ревью рендера:** `render.mjs` headless-сборки строился по инструкции «manifest нет» →
  `[[ID]]` он отрендерит заглушкой. На ревью: подключить `proof1\manifest.json` и резолвить `[[ID]]`
  в название; затем перерендерить из исправленного источника.
