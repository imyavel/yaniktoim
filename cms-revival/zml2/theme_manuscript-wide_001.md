# Theme Spec — `manuscript-wide` (001)

> Источник: `v2_manuscript/index.html` + `v2_manuscript/run.log`.
> Все значения извлечены из фактического CSS макета. `rem` считается от корневого `html` (font-size не задан → **16px**); `em` — от текущего контекста. Базовый кегль текста `body` = **19px**, `line-height` = **1.7**.

---

## 1. Идентичность темы

- **Имя:** `manuscript-wide` (Иллюминированный манускрипт, широкий формат).
- **Эстетика:** рукописный кодекс / иллюминированный свиток. Пергамент, киноварные рубрики, золото, индиго-чернила. Визуальный язык богослужебной книги, перенесённый на широкий «разворот».
- **Общее впечатление:** тёплая бумага под мягким виньетированием, обрамлённая золотой рамкой страница-«манускрипт» с угловыми флеронами; центрированная мастхед-композиция, далее ритмичные блоки с золотыми разделителями-флеронами.
- **Контейнер / ширина:**
  - Внешний `.scroll`: `width:90vw; max-width:1280px; margin:0 auto;` отступ `padding:clamp(20px,4vw,64px) 0`. Это **широкий** формат (потолок 1280px).
  - Внутренний `.manuscript`: золотая рамка `border:2px solid #8a6a1c`, внутренний паддинг `clamp(28px,5vw,84px) clamp(20px,5vw,88px)`, фон `linear-gradient(#f7eed9,#f3e7cd)`, многослойная тень (включая `0 26px 60px -30px rgba(60,40,15,.55)`).
- **Сетка:**
  - Основной поток одноколоночный (центрированный мастхед, секции).
  - Эпиграфы: `display:grid; grid-template-columns:5fr 7fr; gap:clamp(20px,3vw,40px)` (узкий левый стих + широкая правая проза; третий эпиграф `grid-column:1/-1`).
  - Стихи и проза-молитва: CSS-`columns:2` (см. §5).
  - Брейкпоинты: `@max-width:880px` → всё в 1 колонку, `body` 17px, `.scroll` 94vw; `@max-width:520px` → буквица 3em, короче линии artline.

- Итоговая рекомендованная шкала: ceiling `4.4rem`, floor running-text `0.86rem`, floor caps-меток `0.72rem`, отношение ≤ ~5×.

## 5. Модель стиха

- **Многоколоночная** через CSS `columns`. `.verse.cols{columns:2; column-gap:clamp(40px,5vw,80px)}`; строфы `.stanza{break-inside:avoid}`. Есть и одноколоночные «возвышенные» блоки (`.verse.exalted` с `max-width:62ch; margin:0 auto`).
- Правило вёрстки (из run.log): одиночный пустой интервал = строка внутри строфы, двойной = граница строфы.
- ⚠ **Корректировка #2 (стрелки-коннекторы порядка чтения):** при `columns:2` поток идёт **сверху-вниз в левой колонке, затем сверху-вниз в правой**. Для длинных многострофных стихов порядок неочевиден (читатель может принять колонки за параллельные голоса). **Требование темы:** добавить лёгкие стрелки-коннекторы направления чтения.
  - **Вид:** тонкий золотой (`#b08a2e`) глиф `↳`/`⤵` в конце последней строфы левой колонки («продолжение внизу справа») и `↱` в начале первой строфы правой колонки; размер `.7rem`, `opacity:.55`, `font-family:'Lora'`. Реализация — `::after` на маркере строфы или отдельный `.flow-hint` span.
  - **Логика включения:** показывать ТОЛЬКО когда (а) блок стиха многоколоночный (`.verse.cols`) И (б) в нём >1 строфы (порядок чтения не очевиден). В одноколоночных `.verse.exalted` и на брейкпоинте `≤880px` (где `columns:1`) — **скрывать** (`display:none`), коннектор там бессмыслен. Это семантически нейтрально (чистый CSS-хинт, см. §8).

## 6. Сноски

- **Модель:** надстрочные якоря в тексте + концевой список-аппарат.
  - Маркер: `<sup class="fn"><a id="rN" href="#fnN">N</a></sup>` — `id="rN"` (точка возврата) ссылается на `href="#fnN"`.
  - Целевая сноска: `<div class="note" id="fnN">` со встроенной обратной стрелкой `<a class="back" href="#rN">↩</a>`.
  - Двусоставный аппарат: короткие библио-ссылки (`.note`, 2 колонки) + большие развёрнутые (`.note-wide`, полная ширина, опц. 2-колоночное тело, либо `.deflist`).
- **Навигация туда-обратно:** `html{scroll-behavior:smooth}` обеспечивает плавный скролл; вперёд по `#fnN`, назад по `.back → #rN`.
- ⚠ **BASELINE (ревью #3) — подсветка активной целевой сноски через `:target`.** В исходном CSS отсутствует, **добавляется как обязательное требование темы:**
  ```css
  .note:target, .note-wide:target{
    background:rgba(156,43,34,.10);          /* лёгкая киноварная заливка */
    box-shadow:-3px 0 0 0 var(--rubric);     /* рубричная линия слева */
    border-radius:0;                          /* острые края — стиль темы */
    transition:background .3s ease;
  }
  .note:target .num, .note-wide:target .num{ color:var(--rubric-deep); }
  ```
  Вид: бумага под активной сноской слегка «теплеет» киноварью `rgba(156,43,34,.10)`, слева появляется сплошная рубричная линия 3px (`#9c2b22`), номер темнеет до `#7d1f18`. Без анимированной рамки — соответствует «острой» эстетике без радиусов.

## 7. КАПС и глифы

- **КАПС оставляем ЛИТЕРАЛЬНО.** Капс-пассажи (Эпиграф II целиком; «возвышенные» строфы Стиха II; финальные блоки молитвы №30) хранятся в данных как заглавные и выводятся как есть — **без `text-transform`, без downcase, без `font-weight:bold`**. Класс `.uc{text-transform:none}` гарантирует, что наследуемый transform не вмешается. Визуальное выделение «голоса» — только через `.exalted` (золотая левая линия + лёгкий трекинг), не через регистр.
- **Глифы/эмотиконы — дословно** (экранированы HTML-сущностями, но визуально буквальны):
  | Глиф | Контекст | Подача |
  |---|---|---|
  | `<\^/>` | авторский знак в заголовке | `.title .glyph` — золото `#b08a2e`, `.62em`, приподнят |
  | `;::)))` | кода Эпиграфа I | в потоке стиха, без спец-стиля (цвет ink) |
  | `;;;;` | рукописный эпитет глав | `.glyphmark` — золото, Marck Script |
  | `;` | колофон/слоган, разделители «Одним словом ; …» | `.sg`/`.colophon .sg` — золото `#b08a2e`, weight 500 |
  | `^` | финальный слоган «Будущее ^ за нами» | `.sg` — золото |
  | `::` | разделитель полей сноски | `.note .sep` — золото `#8a6a1c` |
  | `^` | внутри текста («Воина^Исраэль», «По^НАСТОЯЩЕМУ») | литерально в теле сноски, без стиля |

  Правило: эмотиконы и пунктуационные глифы **не нормализуются** (никакой замены `::` → `:`, `;;;;` → `;` и т.п.). Тема лишь раскрашивает выделенные позиции (золото) через обёрточные span'ы, заданные данными.

## 8. Семантика vs Оформление

### Чисто CSS (целиком уходит в тему, данные не меняются)
- Все цвета, шрифты, тени, рамки, виньетка, флероны/угловые символы (`\2042`, ✾, ❖, ☉).
- Двухколоночная вёрстка стиха/прозы/сносок (`columns:2`) и зазоры — раскладочное решение.
- Буквица `.dropcap` (можно включать через CSS `:first-letter` или маркером в данных — см. ниже спорный пункт).
- Визуальное выделение `.exalted` (золотая левая линия) для капс-пассажей.
- `:target`-подсветка активной сноски (§6).
- Стрелки-коннекторы порядка чтения (§5) — чистый CSS-хинт на основе раскладки.
- Трекинг/caps служебных меток (eyebrow, tag, section-label, artline).
- Размеры тип-скейла и их clamp-границы.

### Требуют семантического различия в ДАННЫХ (общий слой ZML 2)
- **Подтип эпиграфа.** I = `verse`, II = `prose/teaching`, III = `banner/wide`. Тема рисует их по-разному (`.frame.epi-verse` / `.frame.epi-prose` / `.epi-wide`), но различить их без флага в данных нельзя. → нужен атрибут `epigraph.kind ∈ {verse, prose, banner}`.
- **Модель/класс сноски.** Короткая библио-ссылка (`.note`) vs развёрнутый комментарий (`.note-wide`) vs структурный список (`.deflist`, как №29). → `footnote.kind ∈ {ref, extended, list}`.
- **Структура полей библио-сноски.** Разделение `См.также/Музыка` · `источник` · `автор` · `ссылка` (`.sep`, `.src`, `.auth`, `.link`) — это семантические поля, а не разметка. → данные несут `{role, source, author, url}`.
- **Нумерация главы / тип секции.** «Стих первый/второй/третий», «Предваряющая молитва» — секции с порядковым номером и ролью (`prayer` vs `chapter`). → `section.role` + `section.ordinal`.
- **Регистр капс-пассажа = смена «голоса».** Капс в данных — носитель смысла (восхождение к молитве), а не оформление. Тема НЕ генерирует капс; он приходит из данных и выводится литерально (§7). → флаг `passage.register = exalted` управляет применением `.exalted`, но сам текст-капс — это данные.
- **Глиф-маркеры** (`<\^/>`, `;;;;`, `;`, `^`, `::`) — части содержания. Тема раскрашивает их через обёртки, но позиции и сами символы задаются данными (`glyph`-span), не выводятся темой.
- **Буквица — спорно.** Если буквица должна стоять у первой строфы каждой главы (а не у первой буквы любого блока), это решение «где ставить» — семантическое (`stanza.dropcap = true`), хотя рендер буквы — CSS.
- **Связка якорь↔сноска** (`rN`/`fnN`) — целостность ссылок задаётся данными (id сноски и обратной ссылки), тема лишь стилизует.
