# Объединённая таксономия ZML 2 (семантика → данные/тема)

**Дата:** 2026-05-29
**Вход:** аудит наследования zml1 (`zml1_inheritance_001.md`), синтез прозы
(`prose_synthesis_001.md`), 5 стих-спек + 5 prose-addenda, SPEC.md zml1.

**Принцип колонки «Куда».** `ДАННЫЕ` = недеривируемая семантика, нужная ≥1 теме или корпусу.
`CSS` = презентация (тема рисует, данные не меняются). `ДЕРИВ` = вычисляется рендером из
позиции/контекста, в данные не пишется. `ДАННЫЕ?` = опциональный атрибут (по умолчанию ДЕРИВ).

**Происхождение.** `zml1` (унаследовано), `темы` (из дизайн-макетов), `оба`, `корпус`
(массовая семантика вне макетов).

## 1. Структура документа

| Семантический тип | Семантика | Куда | Происхождение | Частота / важность |
|---|---|---|---|---|
| **frontmatter** (`title/art/date/summary/image`) | id + метаданные; byline + colophon | ДАННЫЕ | zml1 / корпус | art 350/350, date 207, image 195 — фундамент |
| **art-id `XYZ[n]`** | универсальный id, кодирует дату; имя файла, цель ссылок | ДАННЫЕ | zml1 | критично |
| **порядок секций** | intro→`##`→сноски-в-конце — жёсткий инвариант | ДЕРИВ (структура) | zml1 / корпус | инвариант рендера |
| **секция `## Заголовок {slug}`** | h2; CAPS→small-caps; slug опц. | ДАННЫЕ (текст) | оба | 184/350 |
| **section `role=`** | preface/epigraph/body/apparatus/colophon/prayer/chapter | ДАННЫЕ? (деф. ДЕРИВ) | темы | role различали все 5 тем; текст кикера — CSS (см. Q5) |
| **section `ord=`** | порядковый номер главы («Стих первый») | ДЕРИВ (счёт глав) | темы | римская/арабская форма — CSS |

| **`term`/`leitmotif`** (резерв, опц.) | каббал. термин / повторяющийся мотив | ДАННЫЕ? | темы | 2/5 (term), 1/5 (leitmotif) — низкий приоритет (Q13) |

## 4. Сноски (тело)

| Семантический тип | Семантика | Куда | Происхождение | Частота |
|---|---|---|---|---|
| **`[^N]:`** | нумерованная сноска; continuation 4-проб → `<br>` | ДАННЫЕ | zml1 / оба | ядро |
| **`[^]:`** | анонимная, префикс «См. также:» | ДАННЫЕ | zml1 / корпус | 77/350 |
| **`[^\|преф]:`** | анонимная с кастомным префиксом | ДАННЫЕ | zml1 | редко |
| `footnote.kind` (ref/extended/term) | хинт «тяжёлая сноска» → fn-wide / 1-кол. | ДЕРИВ (длина/контент) | темы | колонки/мера — CSS; не нужен явный атрибут (Q16) |
| `footnote.sourceType` («Музыка::»/«Цитата::») | тип источника | ДЕРИВ (литерально в теле) | темы | автор уже пишет «Музыка: X» в теле |
| `footnote.orphan` | нет inbound-маркера в тексте | ДЕРИВ (нет `[^N]`) | темы | 5/5 факт данных; политика показа — Q11 |
| `ref↔fn` пара + `↩` backref | связь маркер↔пункт↔возврат | ДАННЫЕ (id) + CSS | zml1 / оба | стиль `:target` — CSS-baseline всех тем |

## 5. КАПС / глифы / escape (сквозной слой)

| Аспект | Решение | Куда |
|---|---|---|
| **КАПС** | литерально как в источнике — без downcase, без bold, без `text-transform` | ДАННЫЕ (регистр); small-caps стиль — CSS |
| **восстановление имён** | Орёл/Творец/… + `^СЛОВО` для вне-списочных | ДЕРИВ + ДАННЫЕ (`^`) |
| **глифы/эмотиконы** | дословно, пунктуация не нормализуется (`::`≠`:`) | ДАННЫЕ |
| **escape `<\^/>`** | литеральный авторский знак; экран. как `&lt;\^/&gt;` | ДАННЫЕ |

## 6. Презентация — целиком в тему (НЕ в данные)

Все цвета/шрифты/тип-скейл/ритм/рамки/фоны/радиусы/тени · `justify`/`hyphens`/мера в `ch` ·
одно- vs многоколоночный поток + стрелки-коннекторы · рендер буквицы (`::first-letter`/`float`) ·
форма номера (CSS-counter, rail vs висячая цифра, римская/арабская) · `:target`-подсветка сносок ·
раскладка аппарата (1/2 кол., fn-wide) · эпиграф баннер-выворотка vs светлая проза ·
кант/глиф blockquote · выравнивание атрибуции по роли · UPPERCASE/трекинг служебных меток
и **текст кикера/eyebrow** («Вступление» vs «Перед началом» — расходился по темам → презентация).
