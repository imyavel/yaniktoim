== РЕНДЕР ДОЛЖЕН ПОДДЕРЖАТЬ (по ZML2_SPEC_007) ==
- Frontmatter YAML: `zml`, `title`, `art`, `date`, `summary`, `editor`, `edited`. Артлайн рендерит
  тема из `art`/`date`. `<title>` = FM `title`.
- On-page H1 `#` (§1.0): показываемый H1 = body `#` если есть, иначе FM `title`. БЕЗ дублирования.
- `[sub]...[/sub]` — подзаголовок/жанр.
- `## Заголовок {slug}` — секции (id=slug), опц. `role=`. Нумерация/форма — CSS, не данные.
- `[epi kind=verse|prose|aphorism]...[/epi]` — эпиграф; класс несёт kind (темы рисуют 3 подтипа
  по-своему). `cite=` опц.
- `[poem]...[/poem]` — стих построчно; лесенка-отступы и пустые строки между строфами сохраняются;
  авто-капитализация первой буквы строки; КАПС-строки ЛИТЕРАЛЬНО (без small-caps/downcase!).
- `[cry]...[/cry]` — эмфатический возглас (standalone). КАПС литерально.
- параграфы (default); строки-рефрены секций (с ведущим пробелом / `[^N]`) — обычные параграфы.
- Сноски: маркер `[^N]` в тексте → `<sup>` + ссылка-якорь. Тело `[^N]:` → нумерованный пункт со
  ссылкой возврата `↩` И подсветкой по `:target`. `[^]:` (анонимная) → пункт `class="anon"` БЕЗ
  `↩` (политика Q11). continuation-строки (отступ) и встроенные в тело `[[art]]`/`[url]` —
  поддержать. sourceType-метки («Музыка:», «Цитата:») — литерально в теле.
- Inline: `[[art]]` (нет manifest — рендерь анкором по тексту-цели/заглушке), `{chapter|N}`,
  `{term|текст}`→`<span class="term">`, `{leit|текст}`→`<span class="leit">`, `[url|анкор]`/`[url]`,
  `_курсив_`. Семейство `{ключ|текст}` различай по ключу.
- Глифы (§5): рендер оборачивает распознанные авторские глифы в `<span class="glyph">`. Whitelist:
  `<\^/>`, `</v\>`, `:)`, `; — )))`, `;::)))`. HTML-экранируй `<`/`>`. `\`,`^`,`/` спец-значения нет.
- КАПС — ВЕЗДЕ литерально (никакого text-transform/small-caps/восстановления имён). `^` спец-смысла
  не имеет (кроме `[^N]`).
